The free version of DaVinci Resolve includes the full Fusion page. So why does one macro on this shelf say **Resolve Studio** while the next one runs on Free?

The answer is in what a macro is made of.

## A macro is a box of other nodes

A Fusion macro is a `.setting` file that describes a group of nodes, how they are wired, and which of their controls show up in the Inspector. It adds no new code of its own. Whatever the nodes inside can do, the macro can do, and whatever they require, the macro requires.

Those nodes come from two families:

- **Native Fusion tools**, such as Merge, Transform, Blur, Background, Color Corrector and Custom Tool. They are part of Fusion itself and work the same on Free and Studio.
- **ResolveFX**, Blackmagic's own effects library. Resolve lets you use these inside Fusion too, which is very handy: effects like lens distortion or halation are one node instead of a small graph. But a part of the ResolveFX library only ships with Studio.

## What happens on Free

If a macro uses a Studio-only ResolveFX, Resolve Free will still load it, but that effect is treated as a Studio feature: it renders with a watermark. That is why every plugin page here has an **Edition** line, and why it says Studio when even one node inside needs it.

## The macros on this shelf

- **[Easy CRT](../../plugins/easy-crt/)** needs Studio. It uses ResolveFX Lens Distortion for the curved tube and ResolveFX Halation for the red glow around highlights, and both are Studio-only.
- **[Easy ASCII](../../plugins/easy-ascii/)** runs on Free. It uses two ResolveFX, Mosaic Blur and Invert Color, and both are included in the free version.
- **[Easy Dither](../../plugins/easy-dither/)** runs on Free. It is built entirely from native Fusion tools, including the dither pattern, which is generated by a Custom Tool instead of loaded from an image.
- **[Easy Bit](../../plugins/easy-bit/)** runs on Free. Its pixel grid, posterize and console palettes are native Fusion tools, and the one ResolveFX it uses, Stop Motion for the frame repeat, is included in the free version.

## Check any macro yourself

Because a `.setting` file is plain text, you can see what a macro depends on before you install it:

1. Open the file in any text editor.
2. Search for `resolvefx`.
3. Each match names one ResolveFX node, for example `ofx.com.blackmagicdesign.resolvefx.LensDistortion`.

No matches means the macro uses only native Fusion tools and will run on Free. If there are matches, compare those effect names with Blackmagic's list of Studio-only features for your version of Resolve, since that list can change between releases.

## Why not avoid Studio-only effects altogether?

Often you can. Most looks can be rebuilt from native Fusion tools, and that is the route Easy Dither takes. But a dedicated ResolveFX is usually faster to render and better tuned than a hand-built version, so for some effects it is the right tool, and the Edition line tells you up front which kind of macro you are getting.
